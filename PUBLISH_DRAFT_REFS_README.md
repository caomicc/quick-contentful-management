# Publish Draft References Script

This script automatically publishes all draft entries that are referenced by published blog posts. It reads from the CSV report generated by `auditBlogPostDraftReferences.js`.

## What It Does

1. Reads `blog_posts_with_draft_references.csv`
2. Extracts all unique draft entry IDs
3. Publishes each draft entry (skips already published, archived, or missing entries)
4. Generates a log file with results

## Prerequisites

- Node.js installed
- `.env` file configured with Contentful credentials
- `blog_posts_with_draft_references.csv` generated from `auditBlogPostDraftReferences.js`

## Usage

### Recommended Workflow

1. **First, run the audit to find draft references:**
   ```bash
   node auditBlogPostDraftReferences.js
   ```

2. **Review the CSV** to see which entries will be published

3. **Dry run to preview changes:**
   ```bash
   node publishDraftReferences.js --dry-run
   ```

4. **Publish the draft references:**
   ```bash
   node publishDraftReferences.js
   ```

5. **Verify by running the audit again:**
   ```bash
   node auditBlogPostDraftReferences.js
   ```

## Command Line Options

- `--dry-run` - Preview which entries would be published without making changes
- `--help`, `-h` - Show help message

## What Gets Published

✅ **Draft entries** referenced by published blog posts

❌ **Skips:**
- Already published entries
- Archived entries
- Missing/deleted entries

## Safety Features

- ✅ **Dry-run mode** to preview changes
- ✅ **Confirmation prompt** before publishing
- ✅ **Duplicate detection** (publishes each entry only once)
- ✅ **Rate limiting** (200ms delay between requests)
- ✅ **Error handling** for each entry
- ✅ **Detailed logging** of all operations
- ✅ **Skips archived/missing entries** automatically

## Use Cases

### Use Case 1: Blog Post References Draft Images
A blog post references images that are still in draft. This script will publish those images so the blog post displays correctly.

### Use Case 2: Related Content Not Published
A blog post has a "Related Posts" section with draft entries. This script publishes those related posts.

### Use Case 3: Draft CTAs or Blocks
Blog posts reference draft blocks, CTAs, or other components. This script publishes them to complete the blog post.

## Important Notes

### Before Publishing
- **Review the CSV** to ensure you want to publish all listed draft entries
- **Check for unfinished content** - some drafts might not be ready for publication
- **Coordinate with content team** - ensure no one is actively editing these drafts

### After Publishing
- Run the audit again to verify all draft references are resolved
- Check a few blog posts on your live site to ensure they display correctly
- Monitor for any content that might need additional updates

### What This Script Does NOT Do
- ❌ Does not publish the blog posts themselves (they're already published)
- ❌ Does not publish archived entries (needs manual intervention)
- ❌ Does not handle missing/deleted entries (they need to be recreated or removed)
- ❌ Does not validate if draft content is ready for publication

## Handling Special Cases

### Archived References
If the CSV shows archived references, you need to either:
1. Unarchive and publish them manually
2. Remove the reference from the blog post
3. Replace with a published alternative

### Missing References
If the CSV shows missing references, you need to:
1. Remove the broken reference from the blog post
2. Recreate the content and link it
3. Find a published alternative

## Troubleshooting

### "CSV file not found"
Run `node auditBlogPostDraftReferences.js` first to generate the CSV.

### "Failed to publish: Entry is archived"
The entry is archived. Unarchive it manually in Contentful or remove the reference from the blog post.

### "Failed to publish: Permission denied"
Check that your `CONTENTFUL_MANAGEMENT_TOKEN` has publish permissions.

### Some entries already published
This is normal - entries may have been published between the audit and this script running, or published by other team members.
